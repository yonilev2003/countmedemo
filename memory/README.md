# memory/ — זיכרון הפרויקט בין סשנים

> סשן ענן (Claude Code on the web / cowork) מקבל **רק את הריפו** — לא את היסטוריית השיחה.
> כל מה שצריך כדי להמשיך נמצא בקוד ובמסמכים כאן. מתעדכן בסוף כל סשן.

## המסמכים

| מסמך | תפקיד | מתי לקרוא |
|---|---|---|
| `README.md` | האינדקס הזה | תחילת סשן |
| `STATUS.md` | איפה אנחנו **עכשיו** — מה נקי, מה חסום, מה פתוח ידנית | תחילת סשן |
| `progress.md` | יומן התקדמות לפי סבבים — מה נבנה ומתי | להבין מאיפה הגענו |
| `decisions.md` | יומן החלטות נעולות + הנמקה (כולל **מדיניות ניהול סשנים**) | לפני שינוי ארכיטקטוני/מוצרי |
| `retro-YYYY-MM-DD.md` | רטרו פר-סשן-גדול: מה הושג + שיעורי התייעלות | כשרוצים את ההקשר המלא |

## אובסידיאן

התיקייה היא vault תקין: ‏Obsidian → ‏Open folder as vault → ‏`memory/` (או הריפו כולו — גם
‏`docs/reviews/` מתקשר). לכל קובץ frontmatter ‏(tags/related) וקישורי `[[wikilinks]]`, כך שגרף
הקשרים עובד. מוסכמות: ‏STATUS = ‏snapshot חי · ‏progress = יומן (append-only, החדש למעלה) ·
‏decisions = נעילות (לא מוחקים, מעדכנים) · רטרו = קובץ חדש פר סשן גדול, מקושר מ-STATUS.
