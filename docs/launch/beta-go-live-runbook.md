## הצעדים שנותרו — לפי הסדר

הסדר מחייב: `אימות דיפלוי → env → גייטינג → תקציב → ניקוי → QA → משתמשים`

### שלב 1 — לוודא שהפרודקשן חי (2 דק')

1. Vercel → פרויקט `countmedemo` (תחת **yonilev2003s-projects**) → Deployments →
   הפריסה של `08b5308` (ואחריה גם התיקונים החדשים) עם `target: production`.

**איך יודעים שזה עבד:** האתר החי מציג את הדשבורד החדש (3 מספרים) ואת "מי לא שילם לי".

---

### שלב 2 — משתני סביבה (5 דק')

2. צור סוד לקישורי המסמכים — בטרמינל: `openssl rand -hex 32`
3. Vercel → Settings → **Environment Variables**, שניהם **Production + Preview**:

   | Key | Value |
   |---|---|
   | `NEXT_PUBLIC_APP_URL` | הדומיין הקנוני עם `https://`, בלי סלאש בסוף |
   | `DOC_LINK_SECRET` | הפלט מסעיף 2 |

**איך יודעים שזה עבד:** אחרי Redeploy — הפקת מסמך → "שיתוף בוואטסאפ" → ההודעה כוללת
שורת "לצפייה במסמך: https://…/d/…" (ולא רק טקסט).

---

### שלב 3 — נעילת המערכת · ✅ בוצע

4. באותו מסך: `AUTH_GATING_ENABLED` = `true` — **Production + Preview**.
   > חובה גם Preview. אחרת כל פריוויו נשאר פתוח עם מפתחות אמיתיים.
5. Deployments → הפריסה האחרונה → **⋯ → Redeploy**.

**למה זה קריטי מעבר לאבטחה:** כשמשתמש לא מחובר, השמירה לשרת מחזירה `false` בשקט
והנתונים נשארים רק בדפדפן. בלי הגייטינג — משתמש בטא שינקה היסטוריה **מאבד את כל
החשבוניות שלו**.

**איך יודעים שזה עבד** (גלישה בסתר):
- `/dashboard`, `/invoices`, `/receivables`, `/coach` → כולם מפנים ל-`/login`
- `/terms`, `/privacy` → **נפתחים** (ציבוריים בכוונה)
- `https://<הדומיין>/api/chat` → **401**

### שלב 5 — ניקוי חשבונות (10 דק')
