## ריצה מלאה

### א. חשבון וסשן

- [ ] התחברות ראשונה בגלישה נקייה → נוחתים בדשבורד (לא בעמוד ריק ולא בשגיאה)
- [ ] סגירת הטאב → פתיחה מחדש → **עדיין מחוברים** (הסשן שורד)
- [ ] לחיצה על הלוגו מכל עמוד → מגיעים לדף הבית, והכותרת מציגה **"לאזור האישי"** ולא "כניסה"
- [ ] לחיצה על "לאזור האישי" → חוזרים לדשבורד עם הנתונים
- [ ] **התנתקות** → הדאטה נעלם מהמסך; ב-DevTools → Application → Local Storage המפתח
      `countme_persona` **נמחק**
- [ ] התחברות מחדש → הנתונים **חוזרים** (הוכחה שהם בשרת ולא רק בדפדפן)
- [ ] כניסה ישירה ל-`/receivables` כשלא מחוברים → מפנה ללוגין, **ואחרי ההתחברות חוזרים
      ל-`/receivables`** (ולא לדשבורד)

### ב. עמידות נתונים — הבדיקה הכי חשובה

- [ ] במכשיר א': הפק חשבון עסקה + קבלה + הוצאה
- [ ] במכשיר ב' (או דפדפן אחר לגמרי), התחבר עם **אותו חשבון** → **כל שלושת הפריטים שם**
- [ ] חזרה למכשיר א', נקה את ה-localStorage ידנית, רענן → הנתונים **חוזרים מהשרת**
- [ ] אותו מכשיר-ב' (או ניקוי localStorage) — פתח **גם** `/coach` ו-`/business-expenses` ישירות
      (לא רק דשבורד/חשבוניות) → נכנסים ישר עם הנתונים האמיתיים, **לא** נזרקים ל-`/setup`
      (03/08: התיקון היה חלקי — כוסה רק 5 מתוך 17 דפים; אם זה נכשל שוב, זה רגרסיה על התיקון הזה)

> נכשל? עצור מיד — סימן שהמשתמש לא באמת מחובר (בדוק ש-`AUTH_GATING_ENABLED=true`).
> בלי זה משתמש בטא שינקה דפדפן יאבד את כל החשבוניות שלו.

### ג. הזנת נתונים ראשונית (`/setup`)

- [ ] משתמש חדש לגמרי (בלי persona) שנכנס לדשבורד → מופנה ל-`/setup`
- [ ] אפשר לעבור את כל השלבים בטלפון בלי לצאת מהמסך / בלי גלישה אופקית
- [ ] ולידציה עובדת: ת"ז לא תקינה נחסמת; שדות חובה ריקים נחסמים
- [ ] הודעות השגיאה בעברית ומובנות (לא טכניות)
- [ ] בסיום → נוחתים בדשבורד עם השם והעסק שהוזנו
- [ ] משתמש חוזר שנכנס שוב ל-`/setup` → הנתונים **ממולאים מראש**, כולל **שנת המס הנכונה**
- [ ] כתוב "הנתונים נשמרים… לפי מדיניות הפרטיות" עם קישור עובד (ולא "אין שמירה בשרת")

### ד. דשבורד

- [ ] **מצב ריק** (משתמש בלי שום מסמך): שלושת המספרים מציגים 0 / "—", יש הודעת פתיחה
      חמה מאיתן, וכפתור "קבלה" **מודגש** ככפתור הראשון להתחיל ממנו
- [ ] אחרי הפקת קבלה: **"הכנסות" גדל בסכום ללא מע"מ** (לא כולל מע"מ!)
- [ ] אחרי הוספת הוצאה: "הוצאות" גדל, ו"היחס" מתעדכן
- [ ] ניסוח היחס נעים ולא מלחיץ ("על כל 100 ₪ שנכנסו, יצאו X ₪")
- [ ] הפקת **הצעת מחיר** → המספרים בדשבורד **לא זזים** (הצעה אינה הכנסה)
- [ ] הפקת **חשבון עסקה** → המספרים **לא זזים**, אבל הצ'יפ "מי לא שילם לי" גדל
- [ ] כל 4 הכפתורים פותחים את המסך הנכון עם **הסוג הנכון כבר מסומן**
- [ ] "העלאת הוצאה" פותח את המגירה; שמירה מעדכנת את המספר מיד
- [ ] הכל נכנס במסך אחד בטלפון בלי גלילה מיותרת

### ה. הפקת מסמכים

- [ ] **עוסק פטור**: אין בכלל אפשרות "חשבונית מס/קבלה"; מופיעה שורת ההסבר
- [ ] **עוסק מורשה**: כל 4 הסוגים זמינים; המע"מ מחושב ומוצג נכון
- [ ] חשבון עסקה: שדה "תאריך יעד לתשלום" מופיע, **ריק כברירת מחדל**, ואפשר להשאירו ריק
- [ ] הצעת מחיר: שדה "בתוקף עד" מופיע
- [ ] **מספור נפרד**: הצעת מחיר מקבלת `Q-…`, חשבון עסקה `BA-…`, וקבלה ממשיכה את
      הסדרה הרגילה — **הצעת מחיר לא "שורפת" מספר חשבונית**
- [ ] ולידציה: סכום 0 נחסם; שם לקוח ריק נחסם
- [ ] מעל 5,000 ₪ במסמך מס — נדרשת ת.ז./ח.פ.; בהצעת מחיר — **לא** נדרשת

### ו. תצוגה ושיתוף מסמך

- [ ] כל סוג מסמך מציג את **הכותרת הנכונה** (קבלה / חשבונית מס/קבלה / חשבון עסקה / הצעת מחיר)
- [ ] בקבלה מופיע אישור קבלת התשלום; **בהצעת מחיר ובחשבון עסקה — לא** מופיע
- [ ] השורות המשפטיות מתאימות לסוג המסמך
- [ ] **אין שום "מספר הקצאה"** על אף מסמך (הוסר — היה מפוברק)
- [ ] "הדפס / PDF" מפיק מסמך נקי (בלי כפתורי המסך)
- [ ] "שיתוף בוואטסאפ" פותח וואטסאפ עם טקסט עברי תקין **וקישור**
- [ ] פתיחת הקישור **בדפדפן אחר בלי להתחבר** → המסמך מוצג יפה ללקוח
- [ ] שיתוף במייל פותח את תוכנת המייל עם נושא וגוף מלאים

### ז. רשימת המסמכים

- [ ] כל המסמכים מופיעים, החדש למעלה
- [ ] כל שורה מציגה את סוג המסמך + סטטוס נכון (שולם / פתוח / באיחור / פג תוקף)
- [ ] סרגל הסכומים סופר **רק מסמכי תשלום** (לא הצעות ולא חשבונות עסקה)
- [ ] סינון לפי שנה/חודש/לקוח עובד
- [ ] "צפייה" פותח את המסמך הנכון

### ח. מי לא שילם לי

- [ ] "כסף בחוץ" = סכום החשבונות הפתוחים בלבד
- [ ] חשבון עסקה עם תאריך יעד שעבר → מסומן **"באיחור"** באדום
- [ ] חשבון עסקה בלי תאריך יעד → נשאר "ממתין לתשלום" (**לא** באיחור)

- [ ] "שליחת תזכורת" → שלושת הסגנונות (עדין/ענייני/אסרטיבי) משנים את הנוסח

- [ ] שליחה בוואטסאפ עובדת; אחרי השליחה נרשם "נשלחו N תזכורות"
- [ ] **"סמן כשולם"** → החשבון יורד מהרשימה, "כסף בחוץ" קטן בהתאם
- [ ] מצב ריק (אין חובות): מסך ירוק ומרגיע, לא שגיאה

### ט. איתן
