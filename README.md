# countme

> AI-native financial-ops לעצמאים בישראל. הדמו הראשון: מילוי טופס 1301 (דו"ח שנתי) בלי רואה חשבון, בליווי AI.

## מה זה

countme לוקח את הנתונים שלך — חשבוניות, הוצאות, פרטי עסק — ומראה לך בדיוק מה למלא בכל שדה של דו"ח 1301 ברשות המסים. כל מספר לחיץ ומגלה את החישוב והמקור. סוכן AI עונה על שאלות בעברית.

## הרצה מקומית

```bash
npm install
npm run dev
```

ואז:
- `http://localhost:3000` — דף הבית
- `http://localhost:3000/demo` — הדמו של 1301 + סוכן

## מבנה הפרויקט

ראה `CLAUDE.md` להסבר מלא של הארכיטקטורה, ההחלטות, וה-Skills שמותקנים. תיעוד זה מתעדכן עם כל החלטה משמעותית.
